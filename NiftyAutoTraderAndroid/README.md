# NIFTY Auto Trader Android starter

Open this project in Android Studio and build the debug APK.

Current version:
- NIFTY-only dashboard
- Paper trading default
- ₹10,000 capital
- ₹800 maximum daily-loss setting
- 3 trades/day limit
- Start/Stop controls
- Upstox integration placeholder

Important: this starter does NOT place live orders. A production version needs OAuth, current Upstox API integration, WebSocket market data, order-state reconciliation, persistence, duplicate-order protection, and compliance checks before live trading.
